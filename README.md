# Cohorts

Паспортизация ИТ-инфраструктуры: **здание › помещение › стойка › устройство › порт › кабель**.
Мобильное приложение на Flutter для Android. Работает полностью офлайн — вся база
лежит на телефоне, ничего никуда не отправляется.

## Что умеет

- **Дерево инфраструктуры**: здания, помещения, стойки, оборудование; устройства
  можно ставить в стойку по юнитам или отмечать меткой на плане помещения.
- **Схема стойки**: вид по юнитам, передняя и задняя сторона, панель портов
  квадратиками (занят/свободен), режим фото модели из каталога.
- **Порты и кабели**: тип, скорость, VLAN, описание; цепочка соединения от порта
  до конца через патч-панели.
- **Каталог моделей оборудования**: 960 моделей и 1734 изображения, докачка
  моделей из интернета, свои модели вручную.
- **Своё оборудование**: свои категории (название, значок, цвет) и произвольные
  поля — под кондиционеры, датчики, ДГУ и всё, чего нет в списке.
- **Обслуживание и ремонт**: журнал работ с плановыми датами, просрочкой,
  стоимостью и исполнителем; история живёт в карточке оборудования.
- **Пароль на базу**: SQLCipher + Argon2id. Пароль нигде не хранится — только
  соль и параметры, поэтому забытый пароль означает потерю данных (о чём
  приложение честно предупреждает и предлагает сделать резервную копию).
- **Обмен данными**: выгрузка в Excel (инвентаризация, кабели, журнал работ,
  полная выгрузка) и JSON-копия базы; импорт JSON с выбором «заменить/дополнить».
- **Массовая загрузка** из `.xlsx`/`.csv`: шаблон, синонимы колонок (русские,
  английские, NetBox), ошибки с номером строки, предпросмотр, защита от дублей.
- **Два языка**: русский и английский, переключатель в разделе «О программе».

## Сборка и запуск

Требуется Flutter (stable), JDK 17 и Android SDK.

```bash
flutter pub get
flutter run                      # запуск на подключённом устройстве
flutter analyze --no-pub         # статический анализ
flutter test                     # автотесты

# release: обфускация кода + отладочные символы отдельно (см. docs/RELEASE-CHECKLIST.md)
flutter build apk --release --split-per-abi \
  --obfuscate --split-debug-info=build/symbols
flutter build appbundle --release --obfuscate --split-debug-info=build/symbols
```

Подпись release настраивается через `android/key.properties` (образец —
`android/key.properties.example`). Файла с паролями в репозитории нет и быть
не должно: он в `.gitignore`.

## Структура

| Папка | Что там |
|---|---|
| `lib/data` | хранилище (drift + SQLite), шифрование базы, импорт и экспорт, массовая загрузка, демо-данные |
| `lib/models` | модели данных: здание, помещение, стойка, устройство, порт, кабель, журнал работ, категория |
| `lib/screens` | экраны приложения |
| `lib/widgets` | общие элементы интерфейса: карточка, строка списка, плитка с числом, подсказка |
| `lib/l10n` | словарь русского и английского языка парами в одной строке |
| `assets/models` | каталог моделей оборудования (изображения) |
| `docs` | план развития, чек-лист релиза, задание независимому проверяющему |
| `test` | автотесты (167) |

## Каталог моделей

`assets/models` собран из открытой библиотеки
[netbox-community/devicetype-library](https://github.com/netbox-community/devicetype-library)
(лицензия CC0-1.0): оттуда взяты изображения моделей оборудования и справочник по
ним. Названия производителей и моделей принадлежат их владельцам.
